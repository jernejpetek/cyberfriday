ByteShift — A Simple Data Unit Converter

A small CyberFriday project inspired by setting up a Kali Linux virtual machine.

HTML CSS JavaScript Web Development

How the idea started

The idea for ByteShift came up while I was configuring my Kali Linux virtual machine. I wanted to give it enough resources to run comfortably, so I started looking at how much RAM, how many CPU cores, and how much disk space I should allocate.

My computer has an AMD Ryzen 5 5600 processor, 16 GB of DDR4 RAM, and a 1 TB SSD. I was considering allocating 8 GB of RAM, four virtual CPU cores, and around 80–120 GB of disk space to Kali Linux.

While checking the memory and disk values, I came across the difference between units like GB and GiB. I remembered learning about decimal and binary units, but I had become a little rusty with the conversions.

Of course, I could calculate everything manually or search for an online converter. But then I thought: why not build my own?

That simple idea turned into ByteShift, a lightweight data unit converter that I could use myself and share with others through CyberFriday.

What is ByteShift?

ByteShift is a simple web-based tool for converting between common digital data units.

It supports bits, bytes, kilobytes, megabytes, gigabytes, terabytes, and binary units such as KiB, MiB, GiB, and TiB.

The goal was to make something small, practical, and easy to understand. There is no account, no installation, and no complicated interface. You just enter a value, choose the units, and get the result.

How does it work?

The converter uses JavaScript to perform the calculations directly in the browser.

Every supported unit has a conversion factor based on bytes. When a value is entered, ByteShift first converts it to bytes and then divides that value by the conversion factor of the selected output unit.

For example, decimal units use powers of 1000, while binary units use powers of 1024.

  • 1 GB = 1,000,000,000 bytes
  • 1 GiB = 1,073,741,824 bytes
  • 8 GiB = 8.589934592 GB

The same principle works for all supported conversions. Bits are handled by using the fact that one byte contains eight bits.

Technologies used

ByteShift was built using three basic web technologies:

  • HTML — provides the structure, input fields, unit selectors, and result display.
  • CSS — handles the layout and visual design, matching the existing CyberFriday light and dark themes.
  • JavaScript — performs conversions, updates results, swaps units, and provides the reset and copy functions.

Everything runs locally in the browser, so the values entered into the converter do not need to be sent to a server.

What I learned

Even though ByteShift is a relatively small project, building it was a useful learning experience.

  • I refreshed my understanding of decimal and binary data units.
  • I practiced using JavaScript to perform calculations and update a webpage dynamically.
  • I learned more about organizing HTML, CSS, and JavaScript files inside an existing website.
  • I gained experience integrating a new tool into CyberFriday while keeping the existing design, navigation, and themes consistent.

Final thoughts

ByteShift started with a very simple problem: I needed to understand a few storage and memory unit conversions while configuring a virtual machine.

Instead of using an existing converter, I decided to turn that small problem into a practical web development project.

It is not a complicated application, but that was never the goal. I wanted to build something useful, learn along the way, and make it available to anyone who might need it.
