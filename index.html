CyberFriday

CyberFriday is a structured cybersecurity learning hub documenting my journey through security theory, certification preparation, technical writeups, tool cheat sheets, and security-focused projects.

Here you’ll find organized cybersecurity notes, concept explanations, command references, and detailed writeups covering topics such as network security fundamentals, ethical hacking principles, vulnerability analysis, and defensive security concepts. Practical tool cheat sheets and curated command lists are included to support structured study and technical understanding. All material is shared openly as part of my learning process to help other students and aspiring security professionals.

CyberFriday is intended strictly for ethical and educational purposes. I do not support illegal or malicious activity, and the content published here is meant to promote responsible learning, professional growth, and a deeper understanding of cybersecurity fundamentals. Responsibility for how the material is used rests entirely with the reader.
